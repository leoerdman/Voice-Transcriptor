## Сборка и установка
- Только `TRANSCRIPTOR_SIGNING_IDENTITY="AntigravityTelegramDev" npm --prefix desktop run dist`. Ad-hoc сбрасывает доступ Accessibility.
- Установка: выйти через osascript quit, проверить, что запись не идёт (`cue] start/stop` в main.log), затем `ditto` в staging и `mv` старой копии в сторону (не `rm`: в бандле есть файлы только для чтения).
